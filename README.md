# 旅人配裝器

《魔物獵人：旅人》配裝工具。排版先對齊常見配裝 App 的結構：搜索配裝、選擇技能、配裝結果、編輯配裝，底部有配裝／百科／收藏／我的。先選武器與想發動的技能，按「搜索配裝」找出組合，也可以固定部位或進去編輯頁改每一件。頁面會列出全部技能（含來源、達上限 ✓、超出上限以紅色標示）與完整戰鬥數值（攻擊、會心、屬性、防禦、耐性、體力加成，條件觸發分開）。繪影副屬性可自行填寫。資料只存在你的瀏覽器，可離線使用，不需付費。

防具、武器、技能各等級效果、套裝、繪影與心得資料來自 [GameWith 繁中 Wiki](https://gamewith.ai/monster-hunter-outlanders/zh-hant)，技能與防禦為各裝備最高稀有度時的數值。畫面為羊皮紙風格的自行繪製介面，沒有使用遊戲或第三方 App 的圖片、標誌或圖示。
